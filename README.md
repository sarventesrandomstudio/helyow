# helyow
Helyow is an open collection of games made by people from everywhere. Every game is contained in a single HTML file — download it, open it in your browser, and play.
No installation. No game engine. No compiler. Just a browser.

## 🎮 Games

Browse the [`games/`](games/) directory to find games contributed by the community.

Download any game and open its `.html` file in your browser. Some games work completely offline, while others may require an internet connection.

## 🤝 Contributing

Anyone can contribute their own games!

### Requirements

- Your game must be contained in a single `.html` file.
- Your contribution must be legal.

That's it. No restrictions on genre, style, size, or gameplay. Offline compatibility is encouraged, but not required.
